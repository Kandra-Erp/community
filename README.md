# Kandra community

Public feedback for [Kandra](https://kandra.tech), the ERP engine for .NET, and Kandra WMS, the warehouse and
trading configuration built on it.

Use [Discussions](https://github.com/Kandra-Erp/community/discussions) for:

- bugs and rough edges you hit in the live demo, a Docker installation or the configuration template;
- ideas and feature requests;
- questions about trying or setting up Kandra.

This repository holds no source code. Kandra is commercial software with a free production tier, not open
source.

## Where to start

- [Try Kandra](https://kandra.tech/try/): the live demo, Docker, the desktop app and the developer template
- [Kandra WMS docs](https://wmsdocs.kandra.tech): setup and user guide
- [Developer docs](https://docs.kandra.tech): building your own configuration

Kandra is in development (pre-1.0); nothing is on sale yet.
